谁能修改这些文件？

四位数字中第一位是特殊位（2 = 继承上级目录的分组），后面依次是本人 / 同组 / 其他人的读(4)、写(2)、执行(1)。

选「只有运行本工具的账号能改」时，如果刮削软件用其他账号运行，它就无法在这个目录里生成海报和 .nfo。

SMB / Windows 共享：Windows 上的刮削软件通过 \\NAS\media 访问时， 实际使用的 Linux 账号往往不由你控制（匿名共享通常是 nobody）。 这种情况直接选「任何账号都能改」最省事；或者在 Samba 共享里用 force user 把写入统一成固定账号，那时选「只有运行本工具的账号能改」就够了。

一般只需要在这里选一项：本工具会按你的选择给新建的目录和文件设置权限。 选带「组」的那项时，新建文件会自动归到上级目录所在的组，之后无需再手动 chmod。 注意：硬链接和源文件是同一份数据，改权限会同时影响源文件。
